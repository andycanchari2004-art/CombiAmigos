# CombiAmigo – Red Escolar Colaborativa (MVP)
## Forma fácil (sin instalar nada)
Abre la carpeta en VS Code > clic derecho en `index.html` > **Open with Live Server**. Entra como conductor en una pestaña y como padre en otra pestaña (mismo navegador). Necesita internet (mapa, rutas, QR).
## Para usar dos PC distintas
Hace falta un servidor: ejecuta `node server.js` y abre la IP que muestra (misma red wifi), o sube `server.js` a un hosting con Node.
